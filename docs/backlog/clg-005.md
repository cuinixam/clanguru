# [CLG-005] Readability options for the analyze graph

**Status**: Open
**Priority**: Medium
**Component**: `src/clanguru/object_analyzer.py`, `src/clanguru/main.py`

**Summary**:
As a user reading a large `analyze` graph, I want to see how strong each dependency is and to reduce the detail shown, so that the graph stays readable.

**Description**:
Today every object is a node and all symbols shared by two objects collapse into one edge without a count. The current options only remove data (`--exclude-isolated-objects`, `--exclude-symbol-pattern`). Three additions:
- each edge carries the number of symbols behind it;
- the edges can be hidden, which leaves the grouped node map;
- the directory tree can be limited to a depth N, which folds deeper objects into their level-N group.

To decide before starting: whether hiding edges and the depth limit are CLI options or controls in the generated HTML report. The edge count is part of the data in both cases.

**Acceptance Criteria**:
- [ ] Each edge in the graph data has the number of shared symbols, shown in the report
- [ ] Edges can be hidden
- [ ] The directory tree can be limited to a given depth
- [ ] The options are documented in the `analyze` docs
- [ ] All existing tests continue to pass
