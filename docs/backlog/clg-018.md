# [CLG-018] Source link before the code block in the generated docs

## Summary

As a reader of the generated source docs, I want the link to a declaration's source location right above its code block, so that I see where the code lives before I read it.

## Description

With `--source-links` (CLG-016), `clanguru docs` writes each declaration's description, then its code block, then the link to its source line. The link sits below the code, so with a long function the reader scrolls past it to find where the code comes from.

## Scope decisions

- **The link goes directly before the code block**, after the description, for every declaration that has a link.
- **Every output format** (MyST, Markdown, reStructuredText) follows the same order, because the order is set in the document structure, not in a formatter.
- Out of scope: the link text and target (unchanged from CLG-016).
- **Three tests are renamed, approved by the author (2026-11-22)**: `test_source_link_ends_each_declaration_section` becomes `test_source_link_precedes_the_code_block_of_each_declaration_section`, `test_source_link_ends_each_class_section` becomes `test_source_link_precedes_the_code_block_of_each_class_section`, and `test_markdown_output_puts_the_source_link_after_the_code_block` becomes `test_markdown_output_puts_the_source_link_before_the_code_block`. They keep their assertions and check the new order.

## Acceptance criteria

- [x] With `--source-links`, each declaration section shows its description, then the source link, then the code block, in every output format
- [x] Without `--source-links`, the output is unchanged
- [x] `pypeline run` is green
