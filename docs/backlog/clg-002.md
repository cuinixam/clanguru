# [CLG-002] Filter object dependencies by the linked map or ELF file

**Status**: In Progress
**Priority**: Medium
**Issue**: #2
**Component**: `src/clanguru/object_analyzer.py`, `src/clanguru/main.py`

**Summary**:
As a user of `analyze`, I want the dependency graph to show only the symbols the linker kept, so that the graph matches the real binary.

**Description**:
Today `analyze` builds the graph from all object files in the compilation database and every global symbol they use from each other. The linker removes many of these dependencies because the symbols are not used. An optional argument gives `analyze` the `.map` or `.elf` file of the linked binary; `analyze` then keeps only the global symbols that appear there.

**Acceptance Criteria**:
- [ ] `analyze` accepts an optional `.map` or `.elf` file
- [ ] With the file given, the graph and the reports contain only symbols present in the linked binary
- [ ] Without the file, the output is unchanged
- [ ] The option is documented in the `analyze` docs
- [ ] All existing tests continue to pass
