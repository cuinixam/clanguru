# [CLG-012] Code snippet for documented types and variables

**Status**: Open

**Summary**:
As a developer, I want a block above a typedef, enum, struct or variable to appear together with that code, so that a reader sees what the block describes.

**Description**:
A `@trace` above a typedef shows only the sphinx-needs item, without the code:

```c
/**
 * @trace Light state
 * type: impl
 * id: SWIMPL_LC-001
 * implements: SWDD_LC-100
 */
typedef enum
{
    LIGHT_OFF,
    LIGHT_ON
} LightState;
```

Above a function, the same block comes with the function's code block. I would like the same here.
