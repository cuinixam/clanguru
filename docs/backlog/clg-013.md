# [CLG-013] Trace blocks inside function bodies

**Status**: Open

**Summary**:
As a developer, I want a `@trace` block inside a function body to become a sphinx-needs item, so that I can trace a part of a function and not only the whole function.

**Description**:
A `@trace` inside a function body creates no need. It only shows as text in the function's code block:

```c
static brightness_t getBrightnessValue(void)
{
#ifdef CONFIG_BRIGHTNESS_ADJUSTMENT_ENABLED
    /**
     * @trace Variable brightness
     * type: impl
     * id: SWIMPL_LC-005
     * implements: SWDD_LC-204
     */
    return RteGetBrightnessValue();
#else
    return 128;
#endif
}
```

I cannot move it above the function, because it belongs to the `#ifdef`.
