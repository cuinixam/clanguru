# [CLG-004] Parse once, reuse the translation unit

**Status**: Open
**Priority**: Low
**Issue**: #8
**Component**: `src/clanguru/cparser.py`, `src/clanguru/main.py`

**Summary**:
As a user who runs both `mock` and `docs` on the same component, I want to parse the sources once and reuse the result, so that the second and later commands are faster.

**Description**:
`mock` and `docs` each parse and preprocess the same files. A new step exports the parsed `TranslationUnit` to a file; `mock` and `docs` can then import it instead of parsing again. The export format must be safe to load (no `pickle` of untrusted files).

**Acceptance Criteria**:
- [ ] One command exports the parsed translation unit to a file
- [ ] `mock` and `docs` accept that file instead of sources and give the same output as from the sources
- [ ] Loading the file cannot run code
- [ ] The workflow is documented
- [ ] All existing tests continue to pass
