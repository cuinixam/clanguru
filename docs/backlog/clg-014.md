# [CLG-014] Link from a trace to its source line

**Status**: Open

**Summary**:
As a developer, I want each sphinx-needs item from a `@trace` block to link to its source file and line, so that I can open the code from the traceability report.

**Description**:
Today I have to search the repository for the need id to find the code. In CI the link should go to the file in the repository; in a local build, to the local file.
