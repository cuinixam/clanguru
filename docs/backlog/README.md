## Notes

- **ID prefix**: `CLG`
- Keep items actionable with clear acceptance criteria
- Do NOT list commit hashes in backlog entries — the backlog is part of the commit itself, so hashes are circular and go stale after squash/rebase
- Every item open to contributors has a GitHub issue, recorded as `**Issue**: #N`. The issue holds the discussion; its body only links to the item. The pull request that closes an item says "Closes #N".
